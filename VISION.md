# Anima 3D — Self-Evolving AI Agents You Can SEE

## The Vision
A 3D virtual workspace where you watch your AI agents evolve in real-time.
See skills mutating, dreams forming, red teams debating, projects being triaged — 
all in an isometric office environment.

Combines: Pepe 2.0 (self-evolving intelligence) + 3D visualization (Claw3D-inspired)

## What Makes This UNIQUE
Nothing like this exists. Period.
- Devin? Terminal-based. You read logs.
- Hermes? Self-improving but invisible. You see text.
- Claw3D? Visualization but no self-evolution.
- Anima 3D? Self-evolving agents you can WATCH evolve.

## Core Experience
- Open the app → see your agent office
- Skill Genome room: watch skills being tested, mutated, evolved with DNA visualizations
- Dream Lab: see creative connections forming between projects at night
- War Room: project health dashboards with live status boards
- Red Team Arena: watch agents debate decisions in real-time
- Meta-Learning Center: see the agent analyzing itself, spotting weaknesses

## Tech Stack
- Frontend: Three.js / React Three Fiber (3D rendering)
- Backend: Connects to OpenClaw Gateway API
- Data: Reads from Anima/Pepe 2.0 skill data files
- Deployment: Self-hosted or cloud

## Target
- Open source on GitHub
- One-command setup
- Works with any OpenClaw instance running Anima skills
